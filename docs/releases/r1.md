# R1 — preview (library 0.1.0, engine 4.3.1+walton.1)

Release notes for the tag `r1` on commit 8c092b6 (`PLAN.md`, gate R, reached 2026-11-21). The tag and the GitHub release, with the two archives attached, are to be made by the owner (`PLAN.md`, Implementation status).

**A preview.** R1 accepts the engine's supported profile (`docs/contracts.md`); the scheme library is not accepted yet. Its repairs are executable interpretations of the book until Phase 5 of `PLAN.md` has checked them, and every record's row in `tools/vv/source_ledger.yml` is still at "mapped".

### Verification (gate R)

- `tools/vv`: 7,164 checks, all pass under `VV_STRICT=1`; the ledger of known failures is empty. Before `PLAN.md` began, 390 of 5,947 checks failed under 24 issues, and the command could evaluate no scheme of `walton.yml`.
- The engines' own unit tests pass, and the concurrency tests pass under the race detector.
- CI runs on Go 1.24.13 and Go 1.27.4; local runs used Go 1.24.7. A fresh clone of the release branch gave the same result.
- **Still to do (D14):** someone who did not write these changes should rerun the strict suite from a clean checkout and check the reference cases (`tools/vv/cases/`) against the book by hand.
